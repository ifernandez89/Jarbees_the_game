### Para Desarrolladores Argentinos: Cómo Configurar GitHub Sponsors

Si querés recibir donaciones en tu propio proyecto:

1. **Requisitos:**
   - Cuenta GitHub (gratis)
   - CUIT/CUIL argentino
   - Cuenta bancaria con CBU
   - Documento de identidad (DNI)

2. **Paso a paso:**
   ```
   1. Ir a: https://github.com/sponsors
   2. Click en "Join the waitlist" (si no tenés acceso aún)
   3. Completar perfil fiscal:
      - Nombre completo
      - CUIT/CUIL
      - Dirección argentina
   4. Conectar cuenta bancaria:
      - Banco: [Tu banco]
      - CBU: 22 dígitos
      - Alias (opcional)
   5. Definir tiers de donación
   6. Escribir descripción del proyecto
   7. Enviar para aprobación (demora 1-3 días)
   ```

3. **Agregar botón al repo:**
   - Crear archivo `.github/FUNDING.yml`:
     ```yaml
     github: [tu_usuario]
     custom: ["https://cafecito.app/tu_usuario"]
     ```

4. **Recibir pagos:**
   - GitHub deposita mensualmente a tu CBU
   - Sin comisiones (GitHub cubre el costo)
   - Retención de impuestos según legislación argentina
